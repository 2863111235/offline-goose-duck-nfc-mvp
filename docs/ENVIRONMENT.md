# 环境配置与技术选型提案

## 1. 本机核验结果

核验日期：2026-09-11。

| 项目 | 当前状态 |
|---|---|
| 操作系统 | Windows，本项目目录位于本地桌面 |
| Node.js | `v24.14.1` |
| npm | `11.15.0` |
| pnpm | `11.3.0`，已安装但 MVP 暂不要求使用 |
| Git | `2.53.0.windows.2` |
| `node:sqlite` | 可以加载，但运行时显示 ExperimentalWarning |
| 当前仓库 | 已初始化 Git，应用依赖由 npm 管理 |

本机已经满足搭建 Node 网页原型的基础条件。当前无需安装数据库服务、Docker、Java、Android Studio 或 Xcode。

## 2. 推荐方案

推荐采用 **Next.js + TypeScript + SQLite 的单体全栈应用**。

选择单体不是为了长期锁定架构，而是为了第一轮现场验证只暴露一个局域网地址：

```text
iPhone / Android
       │  NFC 打开 http://电脑局域网IP:3000/nfc/...
       ▼
Next.js 网页与接口（同源、同端口）
       │
       ▼
本机 SQLite 文件
```

相较于分别启动 Vite 前端和 API 服务，这一方案少一个端口、没有跨域配置，也不需要在标签写入后区分开发地址和接口地址。相较于原生 iOS App，它可以先在 Windows 上完成验证，不涉及苹果开发者账号、签名或 App Store。

### 依赖管理

建议第一版使用 npm。虽然本机已有 pnpm，但 npm 随 Node 安装，其他测试电脑复现环境时步骤更少。依赖版本应在初始化时锁定，不在文档中猜测最新版。

### SQLite 驱动：已选择

第一版使用 Node.js 24 自带的 `node:sqlite`：

- 不需要单独安装数据库服务或原生数据库依赖；
- 避免 Windows 安装 `better-sqlite3` 时因缺少预编译包而要求 Visual Studio C++ 工具链；
- 事务由项目内的最小封装统一执行，关键写操作仍使用 `BEGIN IMMEDIATE`、提交和异常回滚；
- 本机 Node 24.14.1 会输出 ExperimentalWarning，这是 MVP 当前已知并接受的提示，不影响安装与现场测试。

最初选择的 `better-sqlite3` 13.0.3 在本机实际安装时进入 `node-gyp rebuild`，并因未安装 Visual Studio C++ 工作负载失败。2026-09-12 据此改用 `node:sqlite`，避免为了本地原型额外安装大型编译环境。未来升级 Node 或更换驱动仍需先讨论，不能暗中切换。

## 3. 局域网运行约定

第一轮不部署公网，电脑与手机连接同一个 Wi-Fi：

- 应用监听 `0.0.0.0:3000`，不能只监听 `localhost`；
- 手机访问 `http://<电脑局域网IPv4>:3000`；
- Windows 防火墙仅放行本次使用的专用网络和端口；
- 路由器最好给电脑设置 DHCP 地址保留，避免重启后 IP 改变导致标签 URL 失效；
- 公共 Wi-Fi 可能开启客户端隔离，不适合本测试；
- 第一批标签先不要设置永久写保护，便于修改 IP 或端口。

示例地址 `192.168.1.20` 只是占位符。写标签前必须用电脑当时的真实局域网 IPv4 替换。

## 4. iPhone 测试约定

第一版标签写入普通 HTTPS/HTTP URL 的 NDEF 记录。iPhone 靠近标签后由系统识别，玩家点击系统提示打开网页。

本 MVP 不使用 Safari Web NFC，也不承诺锁屏、后台或完全无点击的交互。第一次现场测试需要逐项确认：

1. 不同 iPhone 型号能否稳定识别标签；
2. 手机是否能访问电脑的局域网地址；
3. 页面打开后本局会话是否仍有效；
4. 连续碰触和刷新是否会被幂等处理；
5. 手机蜂窝网络与 Wi-Fi 切换是否导致访问失败。

## 5. 拟议环境变量

示例值见项目根目录 `.env.example`。其中：

- `HOST`、`PORT` 控制本地监听；
- `PUBLIC_BASE_URL` 是写入 NFC 标签的网址前缀；
- `DATABASE_PATH` 指向本地 SQLite；
- `SESSION_SECRET` 运行前必须换成随机值；
- 击杀和任务冷却先按现有规则文档的 5 分钟与 3 分钟设置；
- 开场保护时间仍待实测，因此做成配置，默认关闭。

## 6. 暂时不需要的环境

- Docker 或云数据库；
- 公网域名、HTTPS 证书和云部署；
- Redis、消息队列或 WebSocket 服务；
- 苹果开发者账号、企业签名或 App Store 上架；
- 微信小程序开发工具；
- USB 写卡器。少量标签先用手机 App 写入即可。

这些项目不是永远排除，而是不应阻塞第一轮 NFC 网页闭环验证。
